# 🎨 LOGO PRONTO - Como Usar

## ⚡ 3 linhas de comando para usar o logo como ícone:

```bash
# Windows
.\create-icons.bat

# Mac/Linux
bash create-icons.sh

# Ou com npm
npm run icons
```

Escolha **UM** dos comandos acima conforme seu sistema.

---

## ✅ É isso!

Os ícones serão gerados automaticamente.

Depois:
```bash
npm run dev
```

Procure pelo botão "Instalar" no navegador. Quando instalar, o logo da empresa aparecerá na tela inicial! 🎉
